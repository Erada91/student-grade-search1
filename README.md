# student-grade-search1# البحث عن درجة الطالب

هذا المشروع يحتوي على صفحة ويب تتيح للطلاب البحث عن درجاتهم باستخدام أسمائهم الثلاثية.

## كيفية الاستخدام
1. افتح الصفحة عبر الرابط: [رابط GitHub Pages سيتم إضافته لاحقًا].
2. أدخل اسمك الثلاثي في حقل البحث.
3. اضغط على زر "بحث" لعرض درجتك.

## الملفات
- `index.html`: صفحة الويب الرئيسية.
- `Medical_Physics.csv`: ملف البيانات الذي يحتوي على أسماء الطلاب ودرجاتهم.
